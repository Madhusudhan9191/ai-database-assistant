This document provides a comprehensive technical overview of the AI Database

--------------------------------------------------------------------------------
1. EXECUTIVE SUMMARY: WHAT IS THIS PLATFORM?
--------------------------------------------------------------------------------
The platform is an AI-powered, self-healing Business Intelligence (BI) tool. 
It enables non-technical business users to query databases in plain English. 
Behind the scenes, it leverages Large Language Models (LLMs) to construct and 
execute structured SQL queries, returning clean data tables, automated analytical 
insights, and dynamic visual charts.

Key Technical Advantages:
* No-Code Querying: Translates natural language into database execution code.
* Intelligent SQL Auto-Repair: Automatically heals syntax or schema errors.
* Containerized Portability: Microservices setup for instant deployment.
* Enterprise Telemetry: Real-time logging, user audit trails, and admin analytics.

--------------------------------------------------------------------------------
2. ARCHITECTURAL EVOLUTION & FEATURE STEPS
--------------------------------------------------------------------------------

The project has been scaled through structured sprints to align with enterprise-grade 
production and monitoring standards:

🚀 STEP 1: Core NL-to-SQL Translation & Execution Engine
Implemented LLM integration to convert user questions to SQL queries. Built a 
secure execution pipeline that connects to relational databases, executes 
queries safely, and formats results.

🚀 STEP 2: Analytical Visualization & KPI Extraction
Added automated chart selection using heuristics and built an insight generation 
service. Results are automatically plotted as interactive charts (bar, line, 
pie, area) alongside plain-English summaries and critical KPI card metrics.

🚀 STEP 3: Multi-User Isolation & Session Control
Introduced JWT-based bearer authentication and password hashing (bcrypt). All 
stored query logs, saved dashboards, and favorite queries are scoped directly to 
the logged-in user's database ID.

🚀 STEP 4: Production Operations & Centralized Logging (Sprint 6)
* Environment Isolation: Converted settings to use Pydantic Settings. Moved 
  secrets out of code into a root-level `.env` file.
* Centralized Logging: Configured rotating file logging handlers (`logs/app.log`, 
  `errors.log`, `auth.log`) capped at 5MB with 5 backups.
* Global Exception Handlers: Handled system crashes gracefully by logging stack 
  traces and sanitizing public API error responses.
* Auto-Repair Engine: Integrated a SQL-repair agent. If a query execution fails, 
  the system catches the DB error, feeds it back to the repair service to reformulate 
  the query, and retries execution automatically.

🚀 STEP 5: Live Telemetry & Admin Command Panel (Sprint 7)
* Telemetry DB Columns: Migrated database schema to track metrics per execution 
  (`repair_attempted`, `repaired`, and `is_admin` flags).
* Uptime & Health APIs: Exposed system health (`/api/health`) and build metadata 
  endpoints (`/api/version`) reporting server uptime.
* Admin Panel API: Created a secure, server-side RBAC-restricted `/admin/stats` 
  endpoint to block non-admins with a `403 Forbidden` error.
* Glassmorphic Control Panel: Built a React Admin Panel highlighting live KPIs, 
  uptime statistics, and historical daily query trends using Recharts.

3. RUN & DEPLOYMENT INSTRUCTIONS
--------------------------------------------------------------------------------

The platform is designed to run seamlessly in either local dev or container modes.

■ Docker Orchestration (Recommended for Production/Demos):
To build images and spin up the complete network, execute from the root directory:
   > docker compose up --build
* Nginx serves the Vite React frontend on port 5173 (redirects calls to backend).
* Uvicorn runs the FastAPI backend on port 8000.
* Volumes are mapped to persist logs and metadata databases across restarts.

■ Local Development Setup:
1. BACKEND:
   * Initialize Python Virtual Environment: `venv\Scripts\activate`
   * Start FastAPI Web Server: `uvicorn app.main:app --reload`
2. FRONTEND:
   * Change directory: `cd ai-db-frontend`
   * Run Vite developer server: `npm run dev`
